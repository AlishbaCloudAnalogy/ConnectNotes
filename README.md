# ConnectNotes

**ConnectNotes** is a ServiceNow application I built to capture people you meet at conferences and events — name, company, notes, and follow-ups — inside a modern **UI Builder** workspace.

| | |
|---|---|
| **Product** | ConnectNotes |
| **Developer** | Alishba Khan |
| **Platform** | ServiceNow (Next Experience) |
| **Workspace** | `/now/connectnotes/home` |
| **Live** | https://dev390713.service-now.com/now/connectnotes/home |

## What it does

- Log contacts after networking conversations
- Store event context (event name, role, date/location met)
- Capture notes and follow-up actions
- Browse and update contacts from a workspace UI

## Stack

- ServiceNow scoped application
- UI Builder / Next Experience workspace
- Tables for contacts and follow-up tasks
- Source control on GitHub

## Deploy

1. ServiceNow Studio → **Create** → **Import app**
2. This repository, branch `main`
3. Open `/now/connectnotes/home`
